# raid-ops

Python-based automation and data tooling for Raid: Shadow Legends built on top of Raid Toolkit (RTK).

## Goals
- Connect to local RTK instance
- Extract structured account data
- Build automation and analysis utilities
- Provide modular, testable Python architecture

## Tech Stack
- Python 3.x
- Raid Toolkit (RTK)
- Async WebSocket client

Initial scaffold.
